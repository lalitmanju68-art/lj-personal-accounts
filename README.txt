LJ Personal Accounts — Offline V1

Included:
- Account Master
- Cash / Bank / Journal / Contra voucher types
- Double-entry transactions
- Day Book
- Ledger
- Trial Balance
- Dashboard balances
- JSON Backup / Restore
- Offline PWA support after first web load

Important:
Browser localStorage is used in V1. Always export backups regularly.
For PWA installation/service worker, serve these files from HTTPS or localhost.
Opening index.html directly can be used for basic testing, but service-worker offline installation requires web hosting/localhost.
